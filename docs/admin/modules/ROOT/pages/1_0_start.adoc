== Introduction

SOGo 6 has been made with orchestration in mind. Meaning it's best used with containerization. However,
you'll still be able to install sogo and use directly in a virtual machine or server.

== Requirements

[WARNING]
====
Requirements is ought to be updated

SOGo 6 is split in half. One part for the UI/Frontend, one part for tha API server/Backend.

=== Backend requirements

All the backends run on Python >= 3.10. As long as you can install it in your OS or image you good to go.

There is also some additionnal C library needed

* https://www.openldap.org/ (e.g. libldap2-dev libsasl2-dev with ubuntu)
* libpq C library for postgresql (e.g. libpq5 with ubuntu)
